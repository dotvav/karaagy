# User Guide

## Configuration Options

Settings can be overridden via environment variables prefixed with `APP_`:

| Environment Variable | Description | Default |
|----------------------|-------------|---------|
| `APP_NAME` | Application title | `My Project` |
| `APP_DEBUG` | Enable debug mode (`true`/`false`) | `false` |
| `APP_HOST` | Host address | `0.0.0.0` |
| `APP_PORT` | Port number | `8000` |
